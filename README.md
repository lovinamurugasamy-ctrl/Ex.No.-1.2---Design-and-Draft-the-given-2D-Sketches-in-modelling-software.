# Ex.No.-1.2-Design and Draft the given 2D Sketches in modelling software.

## AIM
 To sketch the given drawing with dimensions using fusion 360 tool.
 
## REQUIREMENTS
 1. Autodesk fusion 360
 2. Windows 10
 3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
 4. 2.5 Mbps or faster download; 500 Kbps or faster upload 
 
 ## PROCEDURE
1. Open Autodesk Fusion 360 and create a new design.

2. Select Create Sketch and choose the XY plane.

3. Draw a vertical construction line and a horizontal construction line through the origin to establish the centre axis of the component.
![image](https://user-images.githubusercontent.com/113594316/198232594-2187c1c1-4e85-437f-99f7-263bb1a3e968.png)
4. Using the Circle tool, draw the central circle and set its diameter according to the given drawing.

5. Create the concentric circular portions around the centre using the Circle tool and apply the required radius dimensions R16 and R32.

6. Draw the four surrounding circular portions symmetrically around the centre using the Circle tool, maintaining the dimensions given in the drawing.
![image](https://user-images.githubusercontent.com/113594316/198232771-48e6582d-4410-430a-a9d4-70e400255580.png)
7. Create the upper and lower curved extensions using the Arc tool and apply the radius dimensions R15 and R21.

8. Connect the outer circular portions using tangent arcs and lines, and apply the required dimensions R20, R21 and R32 to form the outer boundary.

9. Create the central four-part opening using arcs and lines. Apply the dimensions R20 and R40 to complete the inner profile.
 ![image](https://user-images.githubusercontent.com/113594316/198232845-1608e574-732c-44b2-9921-39e920b70e2e.png)
 
10. Use the Trim (T) tool to remove unwanted portions of circles and arcs and obtain the required shape.

11. Apply the required horizontal and vertical dimensions using the Sketch Dimension (D) tool, including the spacing dimensions 20 mm, 50 mm and 50 mm as shown in the drawing.
![image](https://user-images.githubusercontent.com/113594316/198232907-8275f39c-9031-4cf4-b0c4-8eb568e477ab.png)
12. Apply geometric constraints such as Coincident, Tangent, Symmetry and Horizontal/Vertical to maintain proper alignment and symmetry.

13. Check the sketch carefully and ensure that the dimensions and curves match the given drawing.

14. Click Finish Sketch to complete the 2D design.
